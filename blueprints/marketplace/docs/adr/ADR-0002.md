# ADR-0002 — Граница Harness и отдельной фабрики

**Статус:** SUPERSEDED BY ADR-0013 (только размещение blueprint); остальная граница доверия сохраняется.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Ядро Harness должно оставаться универсальным и независимым от технологического стека.

## Решение
Исходно: Potato Harness — control plane; Marketplace Factory — отдельный blueprint repo; generated project — отдельный runtime. Размещение blueprint внутри общего репозитория теперь определяет ADR-0013. Valera только координирует, 8 ролей сохраняются.

## Последствия и компромиссы
Требуются versioned adapters, API/data contracts и независимые репозитории; не переписывать существующий controller, broker, leases, publisher.

## Альтернативы
Отклонено: включить Django/Swarm-модули в универсальное ядро.

## Проверяемые критерии
Проверка: генератор не импортируется ядром, а модель не имеет прямого доступа к Docker socket/secret.
