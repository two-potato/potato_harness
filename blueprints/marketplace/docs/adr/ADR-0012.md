# ADR-0012 — Acceptance: один реальный вертикальный сценарий через пять сервисов

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Владелец назвал first success реальный сквозной прогон через все пять сервисов.

## Решение
Сценарий listing→moderation verdict→Django publish→OpenSearch search→recommendations→ClickHouse ingestion→mock Telegram/email delivery в локальном Swarm. Плюс negative failure/replay и документированные evidence по SHA. No live AI models.

## Последствия и компромиссы
Меньше фич в первом релизе, но гарантированно проверяемая архитектура вместо демонстрационных заглушек.

## Альтернативы
Отклонено: считать запуск контейнеров или успешный unit mock достаточной приемкой.

## Проверяемые критерии
Проверка: независимое QA доказывает все пять сервисов и сохраняет trace/evidence по точному Git SHA.
