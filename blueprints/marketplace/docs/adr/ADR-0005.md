# ADR-0005 — Nginx edge + отдельный Kong API Gateway

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Требуется самостоятельный gateway, при этом Nginx уже выбран как edge proxy.

## Решение
Nginx — TLS/UI/static/edge; Kong Gateway OSS DB-less — API routing/policies. Внутренние сервисы не обязаны проходить через публичный gateway. Административные endpoints закрыты.

## Последствия и компромиссы
Появляется дополнительный hop и конфигурация. Не повторять rate policies в двух местах; distributed quotas подтверждать для точной версии Kong.

## Альтернативы
Отклонено: только Nginx; также не вводить service mesh до измеренной необходимости.

## Проверяемые критерии
Проверка: route matrix, negative tests на внутренние порты, отсутствующие Admin API и обязательные auth scopes.
