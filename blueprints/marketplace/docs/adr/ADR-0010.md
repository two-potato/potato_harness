# ADR-0010 — Версионированная кастомизация и обновление

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Независимые проекты развиваются по одному шаблону, но отличаются модулями и оформлением.

## Решение
Blueprint registry + pinned lock + поддерживаемые module/theme extension points; генератор воспроизводим. Upgrade через reviewable diff, compatibility checks, expand/contract migrations и rollback.

## Последствия и компромиссы
Нужно сопровождать версии шаблона и миграции; произвольные правки vendor core затрудняют обновление.

## Альтернативы
Отклонено: копировать шаблон однажды без возможности контролируемого upgrade.

## Проверяемые критерии
Проверка: два проекта из одного blueprint и оба обновляются без потери кастомизации.
