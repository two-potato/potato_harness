# ADR-0001 — Независимый marketplace на каждого заказчика

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Возможна SaaS multi-tenant модель, но она не соответствует выбранной владельцем бизнес-модели.

## Решение
Каждый выпуск — отдельные Git, PostgreSQL project database, object storage namespace/bucket, Swarm stack, secrets, CI, backup и blueprint.lock. Никакой shared commerce tenant DB.

## Последствия и компромиссы
Проще изоляция данных и контрактная разработка, дороже инфраструктура на заказчика. Нужны генератор, registry, механизм версии и массового обновления.

## Альтернативы
Принятая альтернатива: отдельные deployments. Отклонена: единая SaaS-мультиарендность.

## Проверяемые критерии
Два проекта не могут подключиться к чужим БД/секретам; Git и deployment раздельны.
