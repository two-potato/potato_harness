# ADR-0007 — Модерация управляет verdict, Django — публикацией

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Отставание модерации или ошибочная асинхронная проверка не должна публиковать запрещённый товар.

## Решение
Новый listing = PENDING_REVIEW; rule-based verdict привязан к content digest/revision. Django авторизует переход при актуальности решения. Human review/appeals сохраняются; недоступность сервиса блокирует публикацию.

## Последствия и компромиссы
Возможно увеличение latency публикации. Необходимы SLA очереди и ручная процедура.

## Альтернативы
Отклонено: сервис напрямую меняет commerce status; автоматическое одобрение при timeout.

## Проверяемые критерии
Проверка: stale verdict rejected, cross-seller denied, outage fails closed.
