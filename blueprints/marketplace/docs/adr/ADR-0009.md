# ADR-0009 — Local-first Docker Swarm с защищённым test runner

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Владелец выбрал локальный Swarm, характеристики машины неизвестны, а модели не должны владеть host privileges.

## Решение
Single-manager dev Swarm, аппаратный preflight, resource-limited basic/advanced; доверенный runner с allowlisted заданиями; Docker socket недоступен агентам. Bubblewrap остаётся fail-closed для своего профиля тестов; интеграционный runner отдельный.

## Последствия и компромиссы
На одной машине нет HA; тяжёлый basic stack требует измерений. Проблемы host namespaces и secret handling блокируют activation.

## Альтернативы
Отклонено: sandbox-off/dev bypass, model-controlled docker commands, объявлять unit mocks полноценным Swarm E2E.

## Проверяемые критерии
Проверка: negative sandbox tests, tenant isolation, реальные service health, denial of Docker socket.
