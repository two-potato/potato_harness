# ADR-0011 — SSR SEO+GEO, REST-first, GraphQL optional

**Статус:** ACCEPTED FOR DESIGN; implementation pending.  
**Дата:** 2026-11-11  
**Контекст:** Potato Marketplace Factory Architecture Baseline v1.

## Контекст
Нужны традиционный поиск и Generative Engine Optimization, но дополнительные API не должны размывать безопасность.

## Решение
Next.js SSR, metadata/canonical/sitemap/hreflang/JSON-LD/Merchant feeds. Достоверные цены и наличие только из Core. Django REST/OpenAPI — основной API; Strawberry GraphQL как read-only optional с cost/depth/object checks. Географический поиск PostGIS — отдельная функция.

## Последствия и компромиссы
Контент и структурированные данные требуют автоматической сверки. GraphQL добавляет N+1 и риск сложных запросов, поэтому не обязателен.

## Альтернативы
Отклонено: GraphQL-only и выдуманные AI-атрибуты/отзывы ради GEO.

## Проверяемые критерии
Проверка: structured data matches published listing; private pages noindex; GraphQL disabled by default.
