# Initial capability broker

Implement the decision boundary in CAPABILITIES.md, then integrate before the
constrained demo's file edit. Trusted host supplies context and fresh grant lookup;
worker output never establishes authority. Check schema, expiry, current policy,
revision, actor/session/workspace and fence. Normalize component-wise relative
paths; reject secret directories, traversal and symlink components. Only initial
read/edit/test decisions are supported. Publication/external effects/network deny.

Tests exercise invalid roles, revoked/stale capabilities and filesystem paths.
This milestone does not supply grant issuance, mediation of arbitrary tools,
process isolation, race-free file IO, leases or artifact publisher. A callback
check is not an OS boundary. Default worker behavior denies absent authorization.
